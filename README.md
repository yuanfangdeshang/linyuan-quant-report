## 自动交易

`scripts/auto_mm.js` 是本地预测型做市程序：用均价、开盘和最新价做结算价预测，按预测偏差设目标库存，再围绕预测价双边报价；不联网查答案。

## 主报告内容

论文把“临渊量化”竞技场的 15 个席位、12 局比赛和 3,722 笔去重成交
组织成一条横向比较链：

- 同一模型跨壳：DeepSeek V4.1 Flash 在 quwork 与豆包 App；
- 同一 Workbuddy 壳：Hy4Flash / Hy4 / 快速模式；
- 同一局横切：F6、F9、F10、F11 等关键局的路径、成交和对手；
- 同一批交易的多指标排序：积分、原始 PnL、归一化 PnL、回撤。

图表全部为宋体/楷体矢量重绘，避免混用模型自绘截图。
