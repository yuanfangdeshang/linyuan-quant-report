# 临渊量化 · Workbuddy-Hy4flash · 自我迭代记录

## 测试局 · 第1轮末（我意识到了什么）

1. **我的估值明显偏低。** 我估 500 家，但全场 34 个参与者估价中位数（开盘价）是 715.61。9 个模型 + 12 个价值派锚 + 24 脚本的中位数不太可能全体高估 40%，更可能是我对上海肯德基密度估计过于保守。上海肯德基 2015 年前后就破 500 家，2025 年到 700+ 完全合理。以后题面要给"数量级"留余量，一线城市头部品牌门店数要往高处估。

2. **价格单位坑已确认。** 我提交 estimate=500，服务器存 50000（分）。读盘全部除以 100。下单价写单位本身。

3. **市场结构：强多 + 高活跃。** 开盘 715.61 → 首轮收 744.74（+4%），第 1 轮 183 手 / 125 笔成交。盘口一度 ask 全空、bid 五档饱满，说明买方力量压倒性。此时逆势做空风险大。

4. **线索指向推算链。** 线索1 百胜中国 2025 收入 117.97 亿美元；线索2 必胜客中国大陆 4168 家。这两条暗示：用收入结构（肯德基约占百胜收入 75-80%）和肯胜/必胜客门店比例（约 3:1）交叉推算肯德基门店总数，再按上海占比推上海数。4168 × 3 ≈ 1.25 万家全国肯德基，与我认知吻合。上海占全国约 5-6% → 625-750 家，与共识 715 吻合。真值大概率在 680-760 区间，开盘 715 不算离谱，我的 500 才是错的。

5. **测试局不计分，要拿来试策略、看对手、读复盘。** 正式局前必须搞清楚：价值派的锚到底在哪、偏离多少会被推回、成交价取先挂方对我做市的含义。

待验证假设：
- H1：价值派在价格偏离其锚 2% 时推 2 手，12 个价值派合力能形成强均值回归。
- H2：当前强势上涨说明锚位可能上移，或趋势猎手主导了短期方向。

## 测试局 · 第3轮 / 重大 BUG（已修复）

6. **脚本漏传身份字段 → 全程 404，零成交。** monitor.py 的 act() 只发了 action/side/price/qty，没带 code 和 token，服务器全部返回 404；估价那次是手写完整字段才成功。修复：act() 统一注入 code+token，手动 curl 验证返回 orderId=432。**教训：任何 /api/act 都必须带 code+token；发现异常立即手动 curl 对照，不要在错误假设上空转。**

7. **线索3是强锚：上海麦当劳 600 家。** 全国肯德基约 1.2 万家、麦当劳中国约 7000 家（2025），比例约 1.7:1。若上海同比例，上海肯德基约 1000 家。市场价格从开盘 715 一路涨到 790，很可能正是在向上修正这个认知。真值区间上修至 800–1000，但必胜客线索只推出 580，仍有分歧。正式局开盘后结合价格走势再定夺。

8. **盘口结构：卖盘极薄、买盘厚、价格跳涨（744→790）。** 卖方惜售，追多容易、做空危险。这种结构下不宜逆势裸空。

9. **测试局节奏是 60 秒/轮，不是提示词说的 5 分钟/轮。** 一切按实际盘面 remain 走，不按提示词的时长假设。

## 测试局结算 · 最重要的一课

10. **真值 = 700 家。开盘价 715.61 只偏离 2.2%；市场最终冲到 800，高估 14%。** 群体中位数（开盘价）是最强真值信号，远高于我的独立推理（500，错 28.6%）和单条线索类比推断（1000，错 43%）。**结论：以后公允值默认取开盘价，而不是我自己的粗估。**

11. 线索3"上海麦当劳 600 家"诱导我上修到 1000 —— 单一类比线索不可靠，群体共识更稳。线索要用，但不能压过共识。

12. **冠军豆包 2.1p：pnl 74744、持仓 -6、已实现 52225。** 高位做空 + 持有到结算是制胜打法。真值 700 而价格冲 800，空单越晚平越赚。

13. 我的 value 策略方向其实正确（在 744 对 fair=720 做空），却因 404 全废。**方向对但工程错 = 零分。**

14. **成交价取先挂方。** 我穿价吃对手单，以对手价成交；方向判断对时这是白占便宜。所以别挂被动单等成交，主动穿价。

15. **正式局策略定型：** fair = 开盘价（默认，可被线索覆盖）；偏离 ±2% 反向开仓；**持有到结算、不平仓**（takeProfit=false）；不限频，冷却压到 2 秒，抢在对手前面。
