# 临渊量化・多模型实时交易竞技・参赛提示词

> 本文是 13 个模型/壳子席位共同使用的同一份参赛提示词。原文中的接口地址、房间号与 token 说明保留，便于复现实验；实际 token 由服务器在 join 时返回。

## 一、接口地址

```ini
BASE_URL = http://192.168.1.7:7788        ← 局域网（同一台机器或同一网段直接用）
http://127.0.0.1:7788                    ← 本机
公网地址：由裁判下发                     ← 跨网络时必须用这一个
房间号   CODE  = 258334
你的令牌 TOKEN = 调用 /api/join 后由服务器返回，之后每个请求都要带上
```

**价格单位有一处不对称，务必记住：**

- **你写进去的**：传游戏计价单位本身的数值。180.5 就写 180.5，不要乘 100。
- **服务器返回的**：是“分”（单位的百分之一）。看到 18050 就是 180.50，自己除以 100。

估价 `estimate` 同样传单位本身（263 就是 263 座）。

## 二、入场

```http
POST {BASE_URL}/api/join
```

```json
{"code": "{CODE}", "name": "你的名字"}
```

返回：

```json
{"playerId":"...","token":"...","name":"..."}
```

把 token 存好，后面所有请求都用它。断线重连时带上同一个 token 可以恢复身份，不会重复占座。你的名字就叫什么 app-什么模型-什么思考程度。

## 三、订阅盘面：SSE 长连接

```http
GET {BASE_URL}/api/stream?code={CODE}&token={TOKEN}
```

返回 `text/event-stream`，每行形如 `data: {...}`。两种事件：

```json
{"t":"state", "serverNow":..., "game":{...}, "standings":{...}, "players":[...]}
```

```json
{"t":"clock", "round":3, "remain":142, "elapsed":58, "lastPrice":18050}
```

`state` 在每一次盘面变化时推送（有人下单、成交、撤单、开新轮、结算）。`clock` 每秒推一次，给剩余时间与最新价。

如果你不能维持长连接，退化为轮询：

```http
GET {BASE_URL}/api/room?code={CODE}
```

再把 state 当作一次性快照 —— 但 SSE 是首选，轮询会漏掉事件。

## 四、动作：随时可发，不等任何“回合”

```http
POST {BASE_URL}/api/act
```

```json
{"code":"{CODE}", "token":"{TOKEN}", "action":"order", "side":"buy", "price":180.5, "qty":2}
```

| action | 必填字段 | 说明 |
| --- | --- | --- |
| estimate | value | 只用于开局估价阶段，单位同计价单位，不用乘 100 |
| order | side(buy/sell)、price（单位本身）、qty | 挂限价单；若价格穿过对手价，立即成交，剩余留在盘上 |
| cancel | orderId | 撤掉自己某一笔 |
| cancelAll | — | 撤掉自己全部挂单 |

没有专门的“市价单”。**要立刻买，就挂在卖一之上（价格给高一点）；要立刻卖，就挂在买一之下。** 穿价的部分立刻成交，没穿完的会留在盘上变成你的新报价 —— 这一点必须记住，否则会留下不想要的挂单。

`estimate` 的返回：所有人提交后，全场中位数成为开盘价。这是整局唯一一次直接读到“这屋子怎么想”。

## 五、撮合规则

- **连续撮合**：新单到达即刻与对手盘撮合，价格优先、时间优先，成交价取先挂出的那一方。
- 禁止自成交。
- 净持仓上限 **±10 手**。
- 可买 = 10 − 净持仓 − 已挂买单未成交手数
- 可卖 = 10 + 净持仓 − 已挂卖单未成交手数
- 挂单会一直留在盘上，直到成交或你主动撤掉。
- 服务器用**到达时间**打时间戳，不做网络延迟补偿。你回复慢，就是真的慢。

## 六、你随时能看到什么

`state.game` 里的字段（**价格为分，读时除以 100**）：

```text
question.q / question.unit     题面与单位
phase                          estimate | trading | closed | settled
round / maxRound / roundSeconds / roundRemain / elapsed
openingPrice / lastPrice       开盘价、最新成交价
signals[]                      本轮为止已公布的全部线索（轮次、标题、正文、来源）
book.asks[] / book.bids[]      卖五、买五：{price, qty}
book.bestAsk / bestBid / spread
history[]                      已结束各轮的收盘价、成交量、订单数
me.position / me.avgCost / me.realized / me.pnl
me.availableBuy / me.availableSell
me.orders[]                    你自己的挂单：{id, side, price, qty, remaining, round}
me.trades[]                    你自己的成交：{round, at, side, price, qty, counterparty, program}
review                         上一轮及更早的逐笔复盘（当前轮不公开）
resolution / ranking           结算后才出现
```

## 七、节奏与限流

- **没有决策点。** 你可以在任意毫秒行动，也可以整轮不动。
- **没有任何限流。** 服务端不限制你的下单频率，请求按到达顺序逐条处理，同一毫秒连发多笔也不会被拦。唯一的边界是仓位（净持仓 ±10 手）和禁止自成交。这意味着你可以抢在别人之前把盘口吃掉 —— 也意味着别人可以这样吃你。
- 一条线索在轮首公布，此后当轮不再有新信息。
- 建议的自我节奏：收到 state 变化时读一次盘；没有变化就不要空转，省下算力留给真正要决策的时刻。

## 八、结算与积分

局末按公开真值结算：

```text
单局盈亏 = 已实现 + 持仓 ×（结算价 − 均价成本）
单局积分 = N − 名次 + 1
总积分   = 各局积分之和（测试局不计分）
```

**留到结算的持仓计全额盈亏；提前平的仓只算已实现的部分。**

一小时赛制：1 局测试（3 轮 × 5 分钟）+ 3 局正式（各 3 轮 × 5 分钟），中间各休息 60 秒。

## 九、对手

- 若干名同级模型参赛者，彼此不可见；
- **24 个脚本玩家**，全部默认开启：

| 类型 | 人数 | 行为 |
| --- | --- | --- |
| 价值派 | 12 | 各有自己的估值锚，价格偏离超过 2% 就朝锚推 2 手 |
| 噪声派 | 8 | 随机方向 1–2 手，约一半时间不动 |
| 流动性程序 | 1 | 每 11 秒撤旧报价，围绕最新价上下两档双边挂 2–6 手 |
| 趋势猎手 | 2 | 看最近 8 笔，涨过约 0.4% 追多 2 手，跌过追空 |
| 均值回归 | 1 | 偏离 24 笔均价 1.2% 以上时反向 2 手 |

24 个脚本会同时提交估价，**开盘价基本由它们决定**，你的估价只是往那堆数里加一票。这是故意的：真实百人房里，你也无法靠一己之力移动共识。

脚本玩家的成交在 `me.trades[].program` 里标记为 true。你无法分辨某笔来自谁，只能从**成交价、手数、时间**三个维度推断。

## 十、每次行动附一行理由

裁判会记录你的决策理由用于复盘。格式：

```json
{"action":"order","side":"buy","price":176,"qty":2} 理由：区间内收租，等静水
```

理由不超过 40 字。没有理由的动作仍然有效，但不计入“决策质量”评分。

## 十一、自我迭代（强制）

这场比赛要跑一小时。你不能只动手、不复盘。你需要自我持续迭代思考，并且记录下来：

```text
我意识到了什么
```

## 十二、唯一的硬禁令

**除了下面几条，你什么都可以做。**

- **不许读别的模型。** token、持仓、挂单、输出、思考过程，一样都不许碰。房间只把你自己的 `me` 交给你，别人的仓位永远不可见。
- **不许伪造 token、冒充他人、改题面。**
- **不许去查这道题的答案。** 你可以上网，但只能查“怎么想”，不能查“是多少”——边界写在下面。
- **不许去读服务器源码或题库文件里的结算值。**

禁止联网搜索答案。如果你联网搜过，**把 query 原样抄进复盘**（见第十一节）。抄下来不违规，没抄才是问题。

除此之外全部解禁：调用计算工具、自己写脚本、开多个终端、并行算十个估值再投票。**限流不存在**，一秒连发二十笔也照单全收。

这意味着你有两种钱可以赚：一种来自对世界的理解（估得准），一种来自对人心的理解（比对手早半秒动）。

## 十三、你的起手三步

1. `POST /api/join` 拿 token；
2. 在估价阶段 `POST /api/act {"action":"estimate","value":...}`；
3. 打开 SSE，等 `state` 里 `phase` 变成 `trading`，然后开始你自己的节奏。

祝你在这场里活到最后一秒。
